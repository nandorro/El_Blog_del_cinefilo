📝 Diario del Proyecto (Entradas)

1. Qué es El Blog del Cinéfilo y cómo se divide la pantalla

El Blog del Cinéfilo nació como una app Android nativa en Kotlin diseñada para consultar de un vistazo las sesiones de los cines de Madrid sin publicidad ni esperas. En esta versión web replicamos las dos franjas principales: Cinesa Méndez Álvaro y Kinépolis Madrid.

2. Arquitectura de datos y códigos de cine

Para evitar los bloqueos anti-bots de las webs comerciales, la aplicación consulta fichas unificadas mediante identificadores únicos (como el código E0247 para Méndez Álvaro y E0453 para Kinépolis), mostrando sesiones agrupadas por versión y estado.

3. Conexión directa con YouTube y webs oficiales

Cada tarjeta de película permite lanzar inmediatamente la búsqueda de su tráiler oficial en español en YouTube con un solo clic, mientras que cada cabecera incluye un acceso directo a la web oficial del cine para comprar entradas.
